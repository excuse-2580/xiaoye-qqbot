手机该挑多大的模型

手机没有独立显存，也没有风扇，跑久了会发热降频。 所以这里是 1B–3B 的舞台，7B 以上留给电脑。

模型体积内存要求体验
Qwen2.5-1.5B-Instruct-Q4_K_M
默认推荐		 约 1 GB 4 GB+ 中文好，短问答、翻译、润色流畅
Qwen2.5-0.5B-Instruct-Q4_K_M 约 0.4 GB 3 GB+ 内存吃紧就换它，速度最快但能力有限
Qwen2.5-3B / Llama-3.2-3B Q4_K_M 约 2 GB 8 GB+ 旗舰机可用，长文本会明显变慢
7B 及以上 4 GB+ 12 GB+ 能加载，但慢到几乎没法聊，不推荐

量化统一选 Q4_K_M——体积和质量的甜点。 在 HuggingFace 下载，国内打不开就把网址里的 huggingface.co 换成 hf-mirror.com。

verified

QQ 官方 API

在 q.qq.com 创建机器人，拿到 AppID 与密钥填进 App。 腾讯官方通道，合规稳定，适合长期运行。

推荐长期使用

swap_horiz

OneBot 反向 WS

在协议端（Lagrange／LLOneBot／NapCat 等）开启反向 WebSocket， App 主动连出去。不用暴露端口、不用内网穿透。

配置最简单

http

OneBot HTTP 上报

协议端把消息 POST 到手机监听端口。上报只负责收， 发消息要反过来调协议端的 HTTP API，两个地址都要填。

需同一局域网

消息规则与限流

触发规则

仅 @机器人（最安静）／前缀触发（如「小夜」或「!」）／关键词／群里全回。 群白名单按群号放行，留空即全部放行。

去重与分段

同一个 message_id 在窗口期内只处理一次，防协议端重复上报； 长回复按字数切成多段，段间留间隔，模拟真人打字。

冷却与并发

同一个群／人的两次回复之间有最小间隔，防止刷屏； 同时处理的消息数有上限，超了直接丢弃，避免把手机 CPU 打满。

密钥安全

Token 与 API Key 经 Android Keystore（AES-256-GCM）加密后落盘， 明文不写入存储；旧版本存过的明文会读取时自动升级。

warning

关于 OneBot 的封号风险

OneBot 属于第三方协议，腾讯并未授权，使用它存在封号风险。 强烈建议用小号测试，不要拿常用的大号冒险。 若要长期稳定运行，请走 QQ 官方 API。

rocket_launch快速开始

四步跑起来

装 APK

下载 app-debug.apk 装到安卓手机（Android 8.0+／arm64）。提示「未知来源」时允许一次即可。

下模型

下载推荐的 Qwen2.5-1.5B-Instruct-Q4_K_M（约 1 GB），传到手机。

选文件并加载

打开 App →「模型」→ 勾选「用手机本地 GGUF」→ 选 .gguf → 点「加载」，等状态变「已就绪」。

接入 QQ（可选）

「机器人」页选接入方式、填参数、设触发规则，点「启动」。App 会以前台服务常驻，锁屏也不断。
